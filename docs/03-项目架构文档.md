# 飞檐拾光 · 非遗拼图长卷 — 项目架构文档

## 一、项目概述

> **项目名称**：飞檐拾光 · 非遗拼图长卷  
> **项目类型**：Web 拼图游戏（中国非遗文化主题）  
> **语言栈**：Java 21（后端）+ HTML5/CSS3/Vanilla JavaScript（前端）  
> **构建工具**：Apache Maven  
> **JAR 包**：`feiyi-game-0.0.1-SNAPSHOT.jar`

---

## 二、整体架构

采用 **单体 JAR 架构**，前后端统一在一个 Maven 项目中，前端资源打包在 JAR 内部，无独立前端构建流程。

```
┌──────────────────────────────────────────────────┐
│                  用户浏览器                        │
│   index.html  /  levels.html  /  game.html       │
└──────────────┬───────────────────────┬───────────┘
               │ GET /                 │ fetch()
               │ GET /levels           │ GET /api/levels
               │ GET /game/{id}        │ GET /api/levels/{id}
               ▼                       ▼
┌─────────────────────────┬─────────────────────────┐
│   PageController        │   LevelApiController     │
│   (Spring MVC @Controller)│   (Spring REST @RestController)│
│   → 渲染 Thymeleaf 模板   │   → 返回 JSON            │
└─────────────┬───────────┴───────────┬─────────────┘
              │                       │
              ▼                       ▼
┌──────────────────────────────────────────────────┐
│                  LevelService                     │
│      @PostConstruct 加载 → 内存缓存 List<Level>    │
└──────────────────────┬───────────────────────────┘
                       │ 解析
                       ▼
┌──────────────────────────────────────────────────┐
│            src/main/resources/data/levels.json    │
│             18 关卡定义（3章 × 6关）               │
└──────────────────────────────────────────────────┘
```

### 数据流补充

```
关卡静态图片 (SVG) ← static/images/levels/
玩家进度 (通关记录) ← window.localStorage
滚动动画状态         ← window.sessionStorage
```

## 三、分层说明

### 3.1 后端层（Java / Spring Boot 4.0.6）

| 层 | 包/文件 | 职责 |
|---|---|---|
| **入口** | `FeiyiGameApplication.java` | Spring Boot 启动类 |
| **配置** | `config/JsonConfig.java` | Jackson ObjectMapper 自定义配置 |
| **控制器** | `controller/PageController.java` | MVC 控制器，返回 Thymeleaf 页面（`/`、`/levels`、`/game/{id}`） |
| **API** | `controller/LevelApiController.java` | RESTful API，返回关卡 JSON 数据 |
| **模型** | `model/Level.java` | 关卡 POJO（包含 title、subtitle、grid、images、culture 等字段） |
| **服务** | `service/LevelService.java` | 启动时加载 `levels.json` 到内存，提供查询接口 |
| **测试** | `test/.../FeiyiGameApplicationTests.java` | Spring Boot 上下文加载测试 |

### 3.2 表现层（Thymeleaf 模板）

| 页面 | 路由 | 模板文件 | 说明 |
|---|---|---|---|
| **首页** | `GET /` | `templates/index.html` | 卷轴展开动画 + 章节入口 + 玩法说明 |
| **图录页** | `GET /levels` | `templates/levels.html` | 关卡列表，支持章节 Tab 切换 |
| **游戏页** | `GET /game/{id}` | `templates/game.html` | 拼图棋盘、计时器、交互、结果弹窗 |

### 3.3 前端层（Vanilla JavaScript）

采用 **多页应用（MPA）** 模式，无框架，JS 按页面拆分：

| 文件 | 职责 |
|---|---|
| `page-effects.js` | 页面通用效果：滚动渐入引擎、Header 状态管理 |
| `ancient-effects.js` | 古韵特效：墨点动画、粒子效果、鼠标拖尾、印章特效 |
| `progress.js` | 基于 `localStorage` 的玩家进度管理器（`FeiyiProgress` API） |
| `scroll-intro.js` | 首页卷轴开场动画序列（滚动/展开/收拢） |
| `home-page.js` | 首页章节进度展示、章节跳转交互 |
| `levels-page.js` | 图录页关卡列表渲染、章节 Tab 切换、进度摘要 |
| `game-page.js` | 拼图引擎：洗牌、拖拽/点击交换、计时、校验、星级评定、弹窗 |

### 3.4 样式层（CSS）

| 文件 | 职责 |
|---|---|
| `base.css` | 设计系统变量（色彩/字体/间距）、CSS Reset、滚动条、导航栏 |
| `ancient-effects.css` | 古韵动画：墨迹、粒子、印章、鼠标拖尾 |
| `index.css` | 首页专属样式 |
| `levels.css` | 图录页专属样式 |
| `game.css` | 游戏页专属样式（棋盘网格、弹窗、倒计时） |

## 四、技术栈详表

| 层级 | 技术 | 用途 |
|---|---|---|
| 后端框架 | Spring Boot 4.0.6 | IoC、MVC、嵌入式 Tomcat |
| 模板引擎 | Thymeleaf | 服务端 HTML 渲染 |
| REST API | Spring MVC `@RestController` | 关卡 JSON 数据接口 |
| 数据序列化 | Jackson 2 | JSON ↔ POJO |
| 前端 | Vanilla ES6 | 无框架，轻量交互 |
| 样式 | CSS3 + CSS Custom Properties | 完整设计 Token 体系 |
| 动画 | CSS `@keyframes` + IntersectionObserver | 滚动渐入、墨迹扩散、印章弹出 |
| 持久化 | `window.localStorage` | 玩家通关进度/最佳时间/星级 |
| 会话状态 | `window.sessionStorage` | 开场动画播放标记 |
| 字体 | Google Fonts: Noto Serif SC, Cormorant Garamond | 中文衬线 + 英文展示 |
| 构建 | Maven + Spring Boot Maven Plugin | 编译打包 `mvn clean package` |
| 开发工具 | `preview-server.mjs` (Node.js) | 前端独立预览，免启动 Spring Boot |

## 五、核心设计模式

### 5.1 拼图引擎（game-page.js）

- **数据结构**：一维数组 `tiles`，每个元素代表当前格子中的图块索引
- **洗牌算法**：Fisher-Yates 随机打乱，保证初始状态非完成态
- **交互方式**：支持 **点击选中交换**（无障碍友好）和 **拖拽交换**（桌面原生）
- **完成检测**：`tiles.every((v, i) => v === i)` 全等判定
- **星级评定**：基于剩余时间比例：≥45% → ⭐⭐⭐，≥20% → ⭐⭐，否则 ⭐

### 5.2 进度管理（progress.js）

- **存储键**：`feiyi-game-progress-v1`
- **存储内容**：每关的 `cleared`（是否通关）、`bestTime`（最佳用时）、`stars`（星级）
- **API 风格**：面向对象封装，提供 `getLevelData()`、`saveLevelData()`、`getSummary()` 等方法

### 5.3 渐进增强

- 核心功能（拼图、计时、交换）不依赖 JS 框架
- 视觉特效（墨点、粒子、拖尾、印章）通过 CSS `@media (prefers-reduced-motion: reduce)` 优雅降级

## 六、数据模型

### 6.1 关卡数据模型（Level.java）

```java
class Level {
    int id;            // 关卡编号
    int chapter;       // 章节：1=建筑，2=画作，3=手工
    String title;      // 关卡标题
    String subtitle;   // 副标题
    String image;      // 图片文件名
    String location;   // 地点
    int difficulty;    // 难度等级
    int grid;          // 网格行列数（如 4 表示 4×4）
    int timeLimit;     // 时间限制（秒）
    String description;        // 简介
    String features[];         // 特征列表
    String culturalSignificance; // 文化意义
    String funFact;             // 趣味知识
}
```

### 6.2 数据来源

| 数据类型 | 来源 | 存储位置 |
|---|---|---|
| 关卡定义 | `data/levels.json` | 服务器内存（`LevelService` 缓存） |
| 关卡图片 | `static/images/levels/*.svg` | 文件系统（共 18 个 SVG） |
| 玩家进度 | `localStorage` | 浏览器本地 |

## 八、服务器配置

| 配置项 | 值 | 说明 |
|---|---|---|
| `server.port` | 7000 | 服务端口 |
| `spring.thymeleaf.cache` | false | 开发阶段禁用模板缓存 |
| `spring.web.resources.cache.cachecontrol.no-store` | true | 禁用静态资源缓存 |
| `spring.http.converters.preferred-json-mapper` | jackson2 | 优先使用 Jackson |

## 十、项目依赖（最小化设计）

```xml
spring-boot-starter-web       # MVC + 嵌入式 Tomcat + REST
spring-boot-starter-thymeleaf # 模板引擎
jackson-databind              # JSON 解析（由 spring-boot-starter-web 引入）

```

无数据库、无前端框架、无状态管理库——刻意保持轻量。
